## Diretrizes de integração
- Manter os vídeos separados por capítulo e cena.
- Preferir MP4 H.264 com áudio AAC, proporção 16:9.
- Não substituir os vídeos originais aprovados; gerar versões otimizadas separadamente.
- Usar carregamento sob demanda e fallback com imagem estática.
- Preservar o progresso, o Merge e os saves existentes.
