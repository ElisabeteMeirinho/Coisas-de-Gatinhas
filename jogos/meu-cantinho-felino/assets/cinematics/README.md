## Situação no GitHub

Este README está versionado neste repositório. Os dois MP4 estão guardados na Biblioteca do ChatGPT, mas **não estão versionados no GitHub**. O conector GitHub disponível nesta sessão grava arquivos de texto, mas não transfere diretamente os binários MP4 locais. Portanto, não referenciar os caminhos planejados no jogo até os vídeos serem efetivamente enviados ao repositório ou a um armazenamento público adequado.

## Diretrizes de integração
- Manter os vídeos separados por capítulo e cena.
- Preferir MP4 H.264 com áudio AAC, proporção 16:9.
- Não substituir os vídeos originais aprovados; gerar versões otimizadas separadamente.
- Usar carregamento sob demanda e fallback com imagem estática.
- Preservar o progresso, o Merge e os saves existentes.
